# Responsive Education Landing Page

A responsive education and online learning website built using **HTML5 and CSS3**. This project focuses on creating a clean, responsive user interface for an educational platform offering online courses.

## Features

* Responsive navigation bar
* Hero section with background image and gradient overlay
* About Us section
* Courses section
* Blog section
* Contact form
* Google Maps integration
* Footer with navigation and contact information
* Mobile, tablet, and desktop responsive layouts
* Font Awesome and Remix Icon integration

## Technologies Used

* HTML5
* CSS3
* Flexbox
* Media Queries
* Responsive Web Design
* Font Awesome
* Remix Icon
* Google Maps Embed

## Responsive Design

The website follows a responsive approach with layouts designed for different screen sizes.

* **Mobile:** Default layout
* **Tablet:** `min-width: 768px`
* **Desktop:** `min-width: 1024px`

The layout changes according to the available screen width using CSS media queries.
